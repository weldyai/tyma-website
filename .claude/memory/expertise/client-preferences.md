# Préférences Client — Brahim

## Ce que Brahim aime
- Design premium, intemporel, sans-serif élégant
- Raleway weight 200 pour les headings — signature luxury
- Palette or/ivoire/brun — pas rose (sauf demande)
- Un seul CTA visible : le bouton WhatsApp flottant
- Animations subtiles et fluides (pas d'effets tape-à-l'oeil)
- Réponses directes, concises, sans blabla
- Code propre et organisé
- Structure claire du projet

## Ce que Brahim n'aime pas
- Uppercase sur la nav (fait "site 2015")
- CTA redondants (header + section + footer = trop)
- Serif fonts sur des projets beauté/mode
- Commentaires de code évidents
- Résumés de fin de réponse ("j'ai fait X, Y, Z...")
- Designs génériques qui ressemblent à tous les autres
- Ajout de features non demandées

## Style de collaboration
- Brahim donne des instructions directes en français ou darija
- Il attend une exécution immédiate sans confirmation inutile
- Si une décision structurelle est nécessaire, demander brièvement
- Livrer du travail terminé, pas des "voici ce que je pourrais faire"

## 2026-04-24 — Tyma / CMS
**Pattern/Erreur :** Sanity rejeté — trop technique, pas visuel, pas intuitif pour un utilisateur non-dev
**Contexte :** Tyma (maquilleuse, non-dev) doit gérer galerie, témoignages, services seule
