## Règle d'enrichissement
Après chaque session significative, le chef-projet ou l'agent concerné ajoute :
- Un pattern qui a fonctionné (avec contexte)
- Une erreur évitée (avec la règle qui en découle)
- Une décision prise et son résultat

**Format d'entrée :**
```
## [Date] — [Projet]
**Pattern/Erreur :** description
**Contexte :** pourquoi ça a marché / échoué
**Règle :** ce qu'on retient pour la prochaine fois
```
