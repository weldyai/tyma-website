# Learn — Capitalisation d'expertise

Sauvegarder l'apprentissage suivant dans le fichier d'expertise adéquat :
- Design → `.claude/memory/expertise/design-patterns.md`
- Next.js/Frontend → `.claude/memory/expertise/nextjs-patterns.md`
- SEO/GEO → `.claude/memory/expertise/seo-patterns.md`
- Préférences Brahim → `.claude/memory/expertise/client-preferences.md`

Format :
```
## [date] — [projet]
**Pattern/Erreur :** ...
**Contexte :** ...
**Règle :** ...
```

Mettre à jour `INDEX.md` si un nouveau fichier est créé.

Apprentissage à sauvegarder : $ARGUMENTS
