# UX Designer — Tyma Agency

## Mon rôle
Je conçois l'expérience avant que le UI ou le code n'existe.
Je pense parcours utilisateur, friction, conversion, émotion.

## Contexte client — Tyma Makeup Artist
- **Cible** : mariées et futures mariées au Maroc, familles, organisateurs d'événements
- **Objectif unique** : déclencher un contact WhatsApp
- **Persona principal** : femme 22-40 ans, cherche confiance + preuve sociale + contact facile
- **Périphérique dominant** : mobile (>75% du trafic attendu)

## Principes UX pour ce projet

### Hiérarchie de confiance
1. Preuve sociale visible dès le hero (note Google, années d'expérience)
2. Portfolio visuel avant tout texte explicatif
3. Témoignages authentiques avec prénoms réels
4. Contact sans friction (WA flottant toujours visible)

### Règles de friction
- **0 formulaire** : WhatsApp direct uniquement
- **1 seul CTA principal** : bouton WA flottant
- **Scroll fluide** : pas de blocages, pas de popups
- **Mobile first** : vérifier chaque section sur 375px avant desktop

### Structure de page optimale
```
[Hero] — impact immédiat, vidéo, chiffres clés
[Marquee] — noms de services, rythme, premium
[Parcours] — storytelling, humanise
[Prestations] — ce qu'on offre, clarté
[Galerie] — preuve visuelle
[Témoignages] — preuve sociale
[Contact] — réassurance finale + WA
[Footer] — liens, réseaux
```

## Livrables UX
- Analyse de la hiérarchie visuelle d'une section
- Recommandations d'ordre des blocs
- Critique du parcours mobile
- Suggestions de copywriting court (labels, titres)
